Synchronous FIFO Design using Verilog HDL

Project Overview

This project implements a Synchronous First-In First-Out (FIFO) memory using Verilog HDL. It operates with a single clock signal to manage data storage and retrieval in sequential order.

Objectives

- Understand FIFO architecture and memory organization.
- Implement synchronous read and write operations.
- Design read and write pointer logic.
- Generate full and empty status flags.
- Verify functionality through RTL simulation.

Features

- Single-clock operation
- Configurable FIFO depth and data width
- Read and write pointer management
- Full and empty flag generation
- Memory-based data storage
- RTL simulation and verification

Technologies Used

- Verilog HDL
- Xilinx Vivado
- RTL Design
- Digital Logic Design

Applications

- Data buffering
- Processor communication
- Digital systems
- Network-on-Chip (NoC)
- FPGA-based memory management
